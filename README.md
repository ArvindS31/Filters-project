# AutoAura Images

A Python program that applies creative filters to car photos. Built as a team project with two others.

## Features

Pick from 10 filters, most with adjustable settings:

1. Checkered flag
2. Warmth
3. Noise
4. Vintage film
5. Old paper
6. Contrast
7. Sharpen and contrast
8. Dim
9. Vignette
10. Cinematic stack

## Requirements

- Python 3
- Pillow (image library)

Install Pillow with:

    pip install pillow

## How to use

1. Put your image in the same folder as `filters_AutoAuraImages.py`.
2. Run the program:
3. Type the image file name (for example `car.jpg`).
4. Choose a filter number and enter the settings it asks for.
5. The edited image is saved in the same folder, with the filter name at the start of the file name (for example `warm_car.jpg`).
